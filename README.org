#+TITLE: HiddenGit

HiddenGit is a self-hosted =soft-serve= Git forge published as a Tor onion service.
This is an experimental setup; for strict security requirements, prefer mature, audited deployments.

* Goals
- Expose Git-over-SSH through an onion address.
- Keep runtime reproducible via Docker and =.env= version pinning.
- Provide operational checks through =run.sh= with =oniux=.

* Ownership Notes (Bind Mounts)
This setup uses local bind mounts:
- =./data/soft-serve= -> soft-serve data
- =./data/tor= -> tor hidden-service state

Because Tor and some setup steps run as root in containers, host files under =./data= can become root-owned.
Practical mitigation options:
- Pre-create directories and chown to your user before first run.
- Run =sudo chown -R \"$USER\":\"$USER\" data/= after teardown if ownership drifts.
- Keep all bind-mounted state isolated under =./data= to avoid polluting repo root.

* Quick Start
#+begin_src shell
./run.sh up
./run.sh status
./run.sh test
#+end_src

Stop stack:
#+begin_src shell
./run.sh down
#+end_src

Run one-shot onion SSH connectivity probe via tor network namespace:
#+begin_src shell
docker compose --env-file .env -f docker-compose.yml -f docker-compose.tor-check.override.yml run --rm tor-check
#+end_src

* run.sh CLI Reference
Usage:
#+begin_src shell
./run.sh <command>
#+end_src

Commands:
- =up= :: Build/start services, then wait until the hidden-service SSH endpoint is connectable through onion routing.
- =down= :: Stop and remove stack services.
- =build= :: Build images only.
- =logs= :: Follow compose logs.
- =ps= :: Show service status.
- =status= :: Show service status and onion hostname (if available).
- =test= :: Validate HTTP and SSH onion connectivity using =oniux=.
- =restart= :: Stop then start again.

* Env Configuration (All Settings)
- =DEBIAN_IMAGE= :: Runtime base image for Tor + soft-serve runtime stage.
- =GO_IMAGE= :: Build image for compiling soft-serve binary.
- =SOFT_SERVE_VERSION= :: Soft Serve version to install.
- =SOFT_SERVE_SSH_PORT= :: soft-serve SSH port.
- =SOFT_SERVE_HTTP_PORT= :: soft-serve HTTP port.
- =SOFT_SERVE_STATS_PORT= :: soft-serve metrics/stats port.
- =SOFT_SERVE_GIT_PORT= :: Git protocol port.
- =ONION_PUBLIC_PORT= :: Onion-side exposed port.
- =ONION_TARGET_PORT= :: Internal target port on soft-serve (usually SSH port).
- =SOFT_SERVE_DATA_PATH= :: Data path inside soft-serve container.
- =SOFT_SERVE_INITIAL_ADMIN_KEYS= :: Optional admin pubkeys for first boot.
- =CI= :: Set to =1= by default; keeps runtime in non-interactive mode and avoids TTY-related sluggish behavior in containerized execution.
- =SOFT_SERVE_SSH_USER= :: SSH username used by readiness checks in =run.sh= (default recommended: =admin=).

* Tips / Tricks

If you do not use ~oniux~, connect to ~tor~ network as you do usually and replace ~oniux~ with ~torsocks~/~torify~ accordingly:

** 1) Example ~/.ssh/config
#+begin_src sshconfig
Host hiddengit
  HostName <ONIONADDRESS.onion>
  User <GIT-USER>
  Port <PORT>
  ProxyCommand oniux nc %h %p
  StrictHostKeyChecking accept-new
#+end_src

Note: if your OpenSSH build does not include =nc=, install netcat and keep the same ProxyCommand pattern.

#+begin_src sh
ssh hiddengit # connect to softserve tui
#+end_src

** 2) Example .git/config using oniux
#+begin_src ini
[core]
	repositoryformatversion = 0
	filemode = true
	bare = false
	logallrefupdates = true
	sshCommand = oniux ssh -p<PORT>

[remote "origin"]
	url = ssh://<GIT-USER>@<ONIONADDRESS.onion>/<REPONAME>.git
	fetch = +refs/heads/*:refs/remotes/origin/*
#+end_src

#+begin_src sh
git pull # with cwd in above git repo should work
#+end_src

Replace =<ONIONADDRESS.onion>/<REPONAME>/<GIT-USER>/<PORT>= with the relevant actual values.

* Project File Map
- =docker-compose.yml= :: Main stack (soft-serve + tor hidden service).
- =docker-compose.tor-check.override.yml= :: Optional one-shot torsocks SSH checker that joins tor container network namespace.
- =Dockerfile.soft-serve= :: Build soft-serve binary and package runtime.
- =Dockerfile.tor= :: Tor hidden-service runtime, renders torrc from template.
- =soft-serve-hidden-service.torrc.template= :: Tor config template with env substitution.
- =run.sh= :: Operator entrypoint for build/start/status/test.
